# 绕过矩阵（类型 → 优先级）

先定性 A–G，再按表执行。每条路线做完都要跑「真开」三检：UI / 本地功能 / API。

## A 纯本地标志

| 优先级 | 手法 | 说明 |
|---|---|---|
| 1 | Frida hook getter → 恒 true | 最快确认门闩位置 |
| 2 | 改 SP / 文件 / 注册表 | 持久；注意类型与备份校验 |
| 3 | smali/PE patch 门闩方法 | `return true` / 改 JZ |
| 4 | 清签名校验后再改包 | 仅当完整性检查挡改包 |

## B 本地算法卡密

| 优先级 | 手法 | 说明 |
|---|---|---|
| 1 | hook `verify(serial)` → true | 先确认唯一校验点 |
| 2 | 还原算法写 keygen | 可分发、可换机时优先 |
| 3 | patch 比较失败分支 | 算法难逆时 |
| 4 | 若误打包私钥 | 直接签任意 LICENSE_BLOB |

## C 在线激活落本地

| 优先级 | 手法 | 说明 |
|---|---|---|
| 1 | 抓激活响应，定位落库字段 | token / expire / sign |
| 2 | 伪造或延长本地 token | 改时间字段 + 重算签名（若有） |
| 3 | hook 响应解析 | 把失败改成功再让原逻辑落库 |
| 4 | 断网后测 | 确认是否真离线可用 |

## D 每次在线强校验

| 优先级 | 手法 | 说明 |
|---|---|---|
| 1 | 先拆「本地功能 vs 云 API」 | 本地扫描/限次/UI 锁仍按 A/G hook |
| 2 | 免费登录先过 | 登录≠付费；拿会话后再测 |
| 3 | hook 客户端门闩 | 证明本地能力可开 |
| 4 | 改响应（mitm）看业务是否信客户端 | 授权抓包环境 |
| 5 | 仅云端仍 403 的部分转 API 审计 | 不要整单判死刑 |

交付必须写清三栏：**本地已开 / 需免费登录 / 仅云端仍拦**。

## A+D 复合（Electron 商户 SaaS / 本地 RPA）

思路优先于工具：先开权益门，再验证执行引擎是否本地。

| 优先级 | 手法 | 说明 |
|---|---|---|
| 1 | 真账号登录（若有） | 拿真 `shopToken`，避免假会话误判 |
| 2 | 强制权益门闩 | `isExpire`/`end_time`/`cms_number`；asar 改赋值或运行时 hook |
| 3 | 过路由/菜单 | 动态菜单（`salememu`）失败会 `resetToken`；需一并处理 |
| 4 | 拦踢下线 | 响应码如 `-101` 异地登录 → 清 token；探 UI 时可拦 `resetToken` |
| 5 | 定性执行引擎 | Playwright 模拟 / 页内 API 截获 / 云 API；本地引擎开了就算本层成功 |
| 6 | 免计费另案 | 算力扣减、云生成仍 D；不要把「进了智能获客页」写成「免算力」 |

Electron 动态探路（附）：`--remote-debugging-port=9222` + CDP 伪造/改写关键响应；持久则改 `app.asar` 门闩比较。

## E 试用 / 时间锁

| 优先级 | 手法 | 说明 |
|---|---|---|
| 1 | 找时间源（`System.currentTimeMillis` / `time(0)` / NTP） | |
| 2 | hook 时间比较 / 改首次运行标记 | |
| 3 | 回拨系统时间（粗暴，仅实验） | 可能被服务端戳穿 |

## F 硬件绑定

| 优先级 | 手法 | 说明 |
|---|---|---|
| 1 | hook 取设备 ID 的函数，固定值 | 便于复用已激活状态 |
| 2 | 从算法中剔除绑定字段 | 需改校验或 keygen |
| 3 | 移植已激活 `license.dat` + 同步 hook 设备 ID | |

## G 第三方 SDK

1. 识别 SDK 名与版本。  
2. 找封装层（App 自己的 `VipManager`）——优先 hook 封装层，少碰 SDK 内部。  
3. 再映射回 A–F。

## Magisk 持久化

| 优先级 | 手法 |
|---|---|
| 1 | LSPosed 模块 hook 门闩 |
| 2 | ZygiskFrida + Gadget script 模式 |
| 3 | smali 改包重签（无 root 框架时） |

## 选择口诀


```
免费登录墙？ → 先登录再测 VIP
能 hook 出真功能？ → 先 hook 定门闩
门闩纯本地？ → 强制 VIP + 拦 sync 写回 FREE
有卡密算法？ → keygen
只激活一次落盘？ → 伪造本地凭证
仅云 API 拒绝？ → 本地仍算开；云端另记类型 D
```
